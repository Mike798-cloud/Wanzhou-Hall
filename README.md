# Wanzhou-Hall
=======
# 晚舟堂：青溪旧事

一款无需服务器、无需依赖的民国乡土叙事解谜网页游戏。

## 运行方式

直接双击 `index.html` 即可游玩，也可以将整个文件夹上传到 GitHub Pages、Netlify 或任意静态网站空间。

## 文件结构

- `index.html`：页面结构与顶部功能入口
- `styles.css`：游戏界面、动态氛围和移动端样式
- `game.js`：剧情、谜题、存档、提示、音效和结局逻辑
- `paywall.js`：1元自愿支持逻辑、首次自动弹出与本地支持记录
- `paywall.css`：自愿支持弹层样式和移动端适配
- `paycode.png`：1元支持收款码
- `assets/`：原创SVG场景图与图标
- `评价与调整思路.txt`：原策划评估与修改说明
- `测试报告.txt`：主流程、付款、存档和移动端测试结果
- `修改说明.txt`：上传与使用说明

## 主要功能

- 五章主线与九个逻辑谜题
- 三种独立结局
- 全程三级免费提示
- 动态色调、天气与程序化背景音乐
- 自动存档、手动存档、备份槽、JSON导入导出
- 便笺、线索板、章节回看
- 1元自愿支持：首次进入游戏自动显示一次，也可从“免费提示”旁主动打开
- 减少动态效果、大字模式、手机端适配

## 自愿支持说明

支持与游戏进度完全分离。不支持也可以游玩全部五章、查看全部三级提示并进入全部结局。点击“已完成支持”只会在当前浏览器记录感谢状态，不会解锁或改变游戏内容。

## 浏览器建议

推荐使用最新版 Chrome、Edge、Firefox 或 Safari。浏览器的自动播放策略要求玩家点击“开始归乡”后才会启用音乐，这是正常行为。
