# 晚舟堂：青溪旧事（水墨江南修订版）

一款无需服务器、无需安装依赖的民国乡土多结局网页解谜游戏。

## 本版重点

- 全面改为烟雨江南淡墨水彩视觉
- 五章主线、九个逻辑谜题和三种结局保持不变
- 对白调整为克制、易懂的民国江南叙事口吻
- 新增细雨环境层、墨雾、宣纸纹理与人物声纹提示
- 保留三级免费提示、便笺、线索板、自动/手动存档
- 保留首次进入游戏自动显示一次的 1 元自愿支持窗口
- 修正故事时间由“民国五十一年”改为“民国四十一年”，与二十年后返乡设定一致
- 修复手机端线索栏造成的横向溢出
- 修复仓库 README 中残留的 Git 合并冲突标记

## 运行方式

直接双击 `index.html` 即可游玩，也可以把本目录全部文件上传至 GitHub Pages。

本项目不需要 BAT、PowerShell、Node.js 或构建工具。压缩包中的文件已经是处理后的最终文件。

## 文件结构

- `index.html`：页面结构和功能入口
- `styles.css`：原有基础布局与交互样式
- `ink-style.css`：本次新增的水墨江南视觉覆盖层
- `game.js`：剧情、谜题、存档、提示、音效和结局逻辑
- `paywall.js` / `paywall.css`：1 元自愿支持模块
- `paycode.png`：支持二维码
- `assets/ink_*.webp`：本次新增的水墨场景图
- `assets/brush-divider.svg`：水墨笔触分隔元素
- `CMD上传命令.txt`：GitHub 上传命令
- `评价与修改说明.txt`：本次评价及调整内容
- `测试报告.txt`：流程和 Bug 检查结果

## 浏览器建议

推荐最新版 Chrome、Edge、Firefox 或 Safari。浏览器要求玩家产生首次点击后才能播放声音，因此琴音、雨声和钟声会在点击“入堂启卷”后启用。

## 自愿支持说明

支持与游戏进度完全分离。不支持也可完整游玩五章剧情、查看全部三级提示并进入全部结局。点击“已完成支持”只在当前浏览器中记录感谢状态，不改变任何游戏内容。
